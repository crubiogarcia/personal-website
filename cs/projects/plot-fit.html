Plot Fit

ALGORITHMS · SPATIAL OPTIMISATION · COMPUTATIONAL GEOMETRY

Collision-based optimisation for arranging building assets along a curve.

Overview

Plot Fit is an algorithm for placing as many building assets as possible along a defined curve without collisions.

Candidate positions are generated and tested iteratively. When elements overlap, their positions are adjusted and checked again, gradually moving the configuration towards a better fit.

The project explores a simple geometric packing problem using placement, collision detection and iteration to search for feasible configurations under spatial constraints.
