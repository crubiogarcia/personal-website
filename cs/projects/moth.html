Moth Grasshopper Plugin

SOFTWARE · GRAPH ALGORITHMS · COMPUTATIONAL GEOMETRY

A fun computational toolkit for geometry, graphs, spatial data and procedural generation · 200+ users

Built with

c# · rhinocommon · grasshopper sdk · xmp core sdk

Moth is a fun toolkit made up of small tools I found useful while working with Grasshopper, a visual programming environment for computational design that runs inside Rhino, a 3D modelling platform.

Over time, these tools grew into a collection of reusable components for things like mesh processing, graph extraction, procedural generation, spatial data and image geolocation.

  • Mesh processing — mesh analysis and face clustering
  • Graph algorithms — extracting graph structures from geometry and working with network relationships
  • Procedural generation — generating urban grids from geometric rules
  • Spatial data — utilities for processing and organising geometric data
  • Image metadata — reading metadata stored in image files
  • Image geolocation — locating images from available geographic metadata

The plugin is written in C# using the Grasshopper and RhinoCommon APIs. Each tool is packaged as its own component and can be combined with others inside a visual programming workflow.

Moth is published through the Rhino Package Manager and has 200+ users.
