Urban Grid Tools

PROCEDURAL GENERATION · SPATIAL ALGORITHMS · RULE-BASED SYSTEMS

Generating urban grids from geometric and spatial rules.

python · grasshopper

Overview

Urban Grid Tools is a Python-based Grasshopper toolset for generating street and block layouts from configurable rules.

The system uses geometric constraints, spatial parameters and a random seed to generate different but reproducible grid configurations.

Rather than drawing each layout manually, the logic of the grid is encoded as rules that control street generation, block formation and the way the geometry responds to different inputs.
